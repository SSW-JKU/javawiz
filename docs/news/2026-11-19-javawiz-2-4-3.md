Title: JavaWiz 2.4.3: Improved plugin and extension console + Improved testing environment
Date: 2026-11-19

JavaWiz 2.4.3 makes the console of your program easier to follow in IntelliJ IDEA and Visual Studio Code, and makes JavaWiz shut down cleanly.

When new output appears, IntelliJ IDEA opens the JavaWiz I/O window and Visual Studio Code shows the JavaWiz I/O terminal, even if you closed or hid it before.
When your program waits for input, every console now says so clearly.
The console also now behaves consistently when stepping back through the history.

JavaWiz now stops completely whenever IntelliJ IDEA or Visual Studio Code closes, also after a crash. Nothing keeps running in the background, and the next start is not blocked.
Steps that take longer than 10 seconds, for example a long calculation, now finish normally instead of ending early.

And the GitHub CI/CD Actions have been revamped and improved.
