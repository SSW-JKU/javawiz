Title: JavaWiz 2.4.2: a clearer Memory View, better data-structure views, and search in the Event History View
Date: 2026-11-18

JavaWiz 2.4.2 makes the **Memory View** easier to follow, improves the **List View** and **Tree View**, and lets you search the **Event History View** for lines of your code.

The **Memory View** shows what changed (again): We restored JavaWiz's behavior that changed variables, fields, array elements, and strings are drawn in red. We newly added that freshly created objects stand out with a red header and border.
Stepping is also calmer: the animations no longer flicker, the heap always stays to the right of the stack, and new objects appear below the existing ones instead of pushing them around.

The **List View** and **Tree View** now show field names in their values, write each object only once, and shorten deeply nested values.
The **List View** draws objects stored in a node with one row per field and keeps working when an object refers back to itself.

Zooming now works the same way in every view, and the **Stream View** has zoom-in and zoom-out buttons. The **Flowchart View** shows complete statements by default instead of cutting them off.

In the experimental **Event History View**, you can now search for any piece of your code, such as `counter + i`, to find every time that line ran. The filter manual explains all search options with everyday examples.
Teaching annotations are now placed beside the element they explain, without covering it or each other.

In Visual Studio Code, Debug with JavaWiz is now offered only for files with a `main` method, so it always starts the program you chose. JavaWiz also uses the Java installation you already set up for Java in Visual Studio Code.
To see which Java installation JavaWiz runs on, click "developed @ JKU" in the toolbar.
