Title: JavaWiz 2.4.1 release notes
Date: 2026-11-08

JavaWiz 2.4.1 is a small update that fixes a few problems with the data-structure views.

The **Array View** no longer stays empty when a program has static array fields. This happened most often in Visual Studio Code.

The **List View** and the **Tree View** no longer stop stepping through a program when a static field points to one of their nodes.

Visual Studio Code now recognizes the same lists, trees, and other data structures as the browser and IntelliJ versions.
