Title: JavaWiz 2.3.1 release notes
Date: 2026-10-27

JavaWiz 2.3.1 fixes a problem that prevented programs from running with Java 27. If you saw an error mentioning “endPositions,” this update should resolve it. The problem was in JavaWiz, so you do not need to change your code.

The Heap memory view now collapses the `args` array by default to keep the display clearer.

We have also improved our internal publishing tools to make future releases easier to prepare and deliver.
