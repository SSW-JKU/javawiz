Title: JavaWiz 2.4.0: Better StreamViz and Java 27 fixes
Date: 2026-11-04

JavaWiz 2.4.0 fixes various Java 27 problems, improves IntelliJ's multi-main handling and makes StreamViz and Memory Viz far more reliable.

On Java 27, there was a deprecation in javac that led to a crash when compiling user programs.
In addition to that, JavaWiz could stop at the first `String.format` or `printf` and wrongly report that the program was waiting for input while it was actually processing.

The IntelliJ plugin now starts exactly the program you chose, even if your project contains several `main` methods.
The toolbar button and the Run menu follow the selected run configuration, the icon next to `main` and the right-click menus start the file you clicked, and Java scratch files can now be debugged too.
And if the plugin runs into an error, you can now report it to us directly from within the IDE.

StreamViz now shows the correct result for every collector and fixes various marble misplacements.
Arrays, lists, and objects in a stream are now drawn with their contents, so you can see exactly which values flow through each step.

The memory view highlights related objects and arrows again when you hover over them, zooms more smoothly, and has a clear Heap header.
Visualizations no longer start partly covered by the navigation buttons, and refreshed colors make the views easier to read.
