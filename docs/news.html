JavaWiz 2.3.0 is here, bringing clearer visualizations and practical improvements for learning, teaching, and exploring Java. Whether you’re following your first program or explaining a complex example to a class, this release makes it easier to see what your code is doing.

The Memory View gives you more control over how much detail you see, including separate options for looking inside Java’s built-in data structures. A new "Show Memory" mode displays clear size breakdowns and heap object size calculations, helping you explore how objects, arrays, and strings use space. Fixes to connecting arrows, expansion controls, and change highlighting also make the diagrams easier to follow.

StreamViz follows more complete stream operations, even when your code spreads them across variables and methods. Results remain visible for empty streams and single-element calculations, while corrected labels, numbers, and connections make it easier to follow each value’s journey. If you use an unsupported parallel stream, JavaWiz now explains the limitation more clearly.

Following changes over time is easier, too: the experimental History View offers separate filters for methods that share a name, clearer help for finding array changes, and fewer distracting entries from Java’s internal workings.

Small interface improvements help you find your way around: visualization buttons now explain their actions when you hover over them, and teaching annotations use lightbulb and question-mark icons. Exported images get filenames containing the date and time, with a notification telling you which file to look for.

Opening projects is more reliable because both IDE integrations skip hidden files that can interfere with loading Java sources. Across the visualizations and editor, fixes also improve how views initialize, update, and close. Behind the scenes, broader checks and maintenance of the release tools support these improvements and future updates.
